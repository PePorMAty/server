# Справочник синонимов продуктов.
#
# Одно вещество в графах называют по-разному: «ИПБ», «Изопропилбензол»,
# «Кумол» — это один и тот же продукт, но для программы это три разные строки.
# Здесь написания одного вещества собраны в одну строку, и первое из них —
# каноническое: именно оно становится идентификатором продукта на графе.
#
# ФОРМАТ
#   Канон | вариант | вариант | ...
#   Строки, начинающиеся с #, и пустые — пропускаются.
#   Регистр и «ё» не учитываются: «Полиэтилён» и «полиэтилен» — одна запись.
#   Дефис и запятая считаются ПРОБЕЛОМ, а не пропадают: «2,4-ДНТ» и «2,4 днт»
#   совпадут, а «24 ДНТ» — уже нет. По той же причине «Орто-ксилол» не
#   покрывает слитное «Ортоксилол»: слитные написания надо выписывать отдельно.
#
# ЧТО ЭТО ДАЁТ
#   — Продукты с разными названиями схлопываются в один узел при объединении
#     графов и при построении по шагам.
#   — Поиск по реестру ГИСП идёт по всем написаниям сразу, а не только по тому,
#     что написано на графе.
#
# ВАЖНО, ПРОЧТИТЕ ПЕРЕД ИСПОЛЬЗОВАНИЕМ
#   Содержимое собрано по общеупотребительным названиям и требует проверки
#   человеком, знающим предметную область. Ошибка здесь не видна глазом: два
#   РАЗНЫХ вещества, попавшие в одну строку, молча сольются в один узел графа.
#   Сомневаетесь в записи — удалите её: отсутствие синонима всего лишь оставит
#   два узла там, где мог быть один, а неверный синоним портит данные.
#
#   Намеренно НЕ включены двухбуквенные сокращения, у которых есть ходовые
#   значения вне химии (ПО, АН, МА, ФА, ПК): цена ошибки выше пользы.
#
#   По той же причине убраны ПЭ, ПП, ПС и БСК: в реестре «ПП 60х27» — это
#   потолочный профиль Кнауф, «ПС 50х50» — стоечный, «БСК» — постамент.
#   Проверить, что приносит сокращение, можно так:
#       node scripts/audit-products.js --abbr
#
#   ЗВЁЗДОЧКА ПЕРЕД НАПИСАНИЕМ — «только для опознания, не для поиска».
#   Справочник служит двум целям сразу, и написание бывает хорошо для одной и
#   вредно для другой. «*ДЭГ» нужен, чтобы узел «ДЭГ» и узел «Диэтиленгликоль»
#   стали одним; но по реестру он приносит одну лишь «Эпоксидную смолу марки
#   ДЭГ-1», где ДЭГ — обозначение марки. Помеченное написание опознаёт узел,
#   но в поиске по реестру не участвует. Канон пометить нельзя: он и есть
#   идентификатор вещества.
#
#   Осторожно с известью: гашёная (гидроксид кальция) и негашёная (оксид
#   кальция) — разные вещества, поэтому «Известь» без уточнения не значится.
