# Граф производства — сервер

API для клиента `PePorMAty/gpt-graph-client`: строит шаги цепочек с
моделями (Qwen/DeepSeek через DashScope или OpenAI), хранит графы, ищет
источники, сверяет продукты со справочниками ОКПД2/ТН ВЭД/ГИСП.
Node.js, Express 5, CommonJS.

## Владелец и порядок работы
- Общаемся по-русски, дружелюбно, с объяснением, что и зачем делаем.
- **Ничего не мержить без подтверждения владельца.** PR — только по просьбе.
- Ветки устроены не так, как в клиенте: какая ветка сейчас на боевом
  сервере, уточняй у владельца. Общая рабочая ветка —
  `claude/combined-testing` (в ней слиты `claude/cloud-product-testing-cg98tm`
  и `claude/beautiful-hamilton-4whfax`); новую работу начинай от неё.
- Боевой сервер — https://sorangptgraph.xyz/api (pm2 за nginx), выкладывает
  владелец. `ecosystem.config.js` — шаблон pm2, не настоящая конфигурация.

## Запуск и проверки
- `node server.js` (порт `PORT`, по умолчанию 3001; проверка — `/api/health`).
  Ключи моделей и подключение к Postgres — в `.env` (в git не попадает).
- `npm test` — тесты разбора шага на подставных ответах модели
  (`test/`, node:test). Линтера нет; минимум для остального — модуль
  загружается: `node -e "require('./routes/step/build.js')"`.
- Промпты обобщения и разбор шага проверяй скиллом `prompt-check`
  (`.claude/skills/prompt-check/`): `--dry` бесплатно, живой прогон — по
  запросу к модели на кейс.
- Свою проверку без модели делай так же, как в `test/`: заглушка в
  `require.cache` для `routes/sources/utils` (там `callOpenAIResponsesRaw`)
  и вызов обработчика роутера напрямую.
- Запросы к живой модели стоят денег — только когда владелец просит или
  без этого не проверить промпт; говори, сколько запросов ушло.

## Карта кода
- `server.js` — монтирование роутеров: `/api/graphs/...` (модель),
  `/api/graph-files/...` (сохранённые графы), `/api/...` (справочники,
  источники из базы).
- `routes/step/` — пошаговое построение: `sources.js` (поиск источников),
  `aggregate.js` (обобщение), `build.js` (разбор шага в узлы + страховки по
  тексту обобщения), промпты — `routes/step/utils/prompts.js`.
- `routes/sources/utils/openai.js` — единый транспорт к моделям (`MODELS.md`).
- `routes/graph-files/` — файлы графов и данные рядом с ними (закладки,
  история, расчёты баланса, идентификаторы) в `data/<вид>/<граф>.json`;
  `data/` не в git.
- `routes/industry/` — справочники и идентификация продуктов
  (`IDENTIFICATION.md`); `routes/local-sources/` — документы в базе
  (`LOCAL-SOURCES.md`).
- `TODO.md` — отложенные договорённости с разбором; читай перед тем, как
  переделывать описанное там.

## Как здесь пишут код
- Комментарии — по-русски; объясняют, почему так.
- Клиент на сайте может быть старее или новее сервера: новые поля ответа —
  необязательные, старые запросы должны работать как раньше.
